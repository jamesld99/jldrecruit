# JLD Recruit Ltd Website

Modern, responsive Next.js website for JLD Recruit Ltd — a family-run UK recruitment agency specialising in automotive, engineering and technical recruitment.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```

## Pages

- **Home** — Hero, sectors, services, FAQ and contact
- **Employers** — Recruitment support for businesses
- **Job Seekers** — Candidate information
- **Sectors** — Automotive, engineering and technical sectors
- **About** — Company story and values
- **How It Works** — Recruitment process
- **Contact** — Contact form and details

## SEO Features

- Semantic HTML with proper heading hierarchy
- Page-specific metadata and Open Graph tags
- JSON-LD schema (Organization, ProfessionalService, LocalBusiness, FAQPage)
- Sitemap and robots.txt
- Clean URLs and internal linking

## Deployment

Deploy to [Vercel](https://vercel.com), Netlify, or any platform supporting Next.js.
